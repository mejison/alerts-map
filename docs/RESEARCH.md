Публічні сторінки: https://alerts.in.ua/, https://map.ukrainealarm.com/, https://neptun.in.ua/.

UkraineAlarm має легенду типів цілей, рівні тривоги, тематичні шари, вибір теми й статистику. NEPTUN документує достовірність, кількість джерел та ймовірний курс. Це стало основою незалежного дизайну ВАРТА: темна карта, компактна панель ситуації, фільтри загроз і мобільна навігація. Історичну статистику й push у v1 не реалізовано.

## API

### NEPTUN — підключено й перевірено

Документація: https://neptun.in.ua/developers
Умови: https://neptun.in.ua/api-terms

- GET https://neptun.in.ua/api/v1/threats — {epoch, seq, serverTime, threats}.
- GET https://neptun.in.ua/api/v1/alerts — {version, updatedAt, raions, oblasts}.
- GET https://neptun.in.ua/api/v1/messages — {messages, updatedAt}.
- wss://neptun.in.ua/api/v1/stream — snapshot, upsert, remove, alerts, heartbeat.
- /oblasts.geojson та /raions.geojson — геометрія з ключами, що відповідають тривогам.

Під час розробки REST endpoints і GeoJSON повернули HTTP 200. WebSocket надіслав початковий snapshot, а браузер отримав живі зміни. Ключі не потрібні; CORS відкритий. REST дозволено не частіше разу на 5 с. ВАРТА опитує власний проксі раз на 15 с, сервер кешує відповіді 15 с у межах процесу; поточні зміни загроз приходять WebSocket.

Атрибуція NEPTUN обов'язкова й постійно видима поруч із картою. Сервіс є агрегатором відкритих повідомлень, не офіційною системою оповіщення. Дані можуть затримуватися.

Правила відображення: areaOnly не перетворюється на точку або курс; advisory має спокійне інформаційне оформлення; heading показується лише коли він заданий і достовірність не низька. destination позначено як ймовірний напрямок. Ми не вигадуємо траєкторій між повідомленнями. trail — лише надана джерелом історія. Давність понад 7 хв приглушує позначку. Геолокація використовується лише локально для центрування карти й не надсилається серверу.

### alerts.in.ua — адаптер підготовлено, потрібен ключ

Документація: https://devs.alerts.in.ua/
Заявка: https://alerts.in.ua/api-request
Офіційний клієнт: https://github.com/alerts-ua/alerts-in-ua-py

GET https://api.alerts.in.ua/v1/alerts/active.json
Authorization: Bearer TOKEN

Має області/райони/громади, тип тривоги, початок, рівень і перелік загроз. Документованих координат рухомих БпЛА в цьому endpoint немає. Додатково є історія /v1/regions/{uid}/alerts/month_ago.json, компактні IoT endpoints v1/v2. Рекомендований ліміт 8–10 запитів/хв на IP, жорсткий — 12; історія — 2/хв. Для публічного сайту обов'язковий серверний проксі; токен не можна розміщувати у браузері. Прямий адаптер без ключа інтеграційно не перевірено.

### UkraineAlarm — адаптер підготовлено, потрібен ключ

Заявка та офіційний доступ: https://api.ukrainealarm.com/
Офіційний SDK: https://github.com/UkraineAlarm/UkraineAlarm-javascript

База https://api.ukrainealarm.com/api/v3
GET /alerts, /alerts/{regionId}, /alerts/status, /alerts/regionHistory, /regions.
Authorization: TOKEN. Є webhook API; ВАРТА не створює webhook-підписок.

Тип AIR відокремлено від інших тривог. Каталог regions.states містить вкладені regionChildIds; адаптер використовує цей каталог, щоб пов'язувати записи з областю. Цифровий rate limit у доступних офіційних матеріалах не підтверджено. Swagger під час дослідження недоступний через Cloudflare, тому контракт перевірено за офіційним SDK. Документованих координат рухомих БпЛА тут немає. Прямий адаптер без ключа інтеграційно не перевірено.

## Межі готовності

NEPTUN забезпечує реальні тривоги та публічні повідомлення вже у v1. Три незалежні джерела не вважаються трьома підтвердженнями одного факту: вони можуть використовувати спільний первинний потік. Відсутність міток не означає безпечну ситуацію.

Для масового навантаження з прямими ключами потрібен централізований збирач/спільний кеш: кеш у пам'яті одного Worker не дає глобальної гарантії rate limit між ізолятами. До запуску прямого ключового провайдера для великої аудиторії це обов'язковий наступний етап. Для громад без власного полігона показується запис у списку регіону; потрібні окремі межі громад для точного локального підсвічування.
