## Наступні етапи, що потребують доступів або окремої роботи

1. Отримати ключі alerts.in.ua / UkraineAlarm; перевірити адаптери на реальному авторизованому контракті, налаштувати спільний кеш/централізований збирач для гарантії лімітів.
2. Додати історію та статистику на збережених даних, не вигадувати ретроспективні події.
3. Розширити геометрію до громад та синхронізувати географічні ідентифікатори між провайдерами.
4. Додати PWA/Web Push із серверними підписками, явним дозволом користувача та без обіцянок гарантованої доставки.
5. Перевірити доступність і навантаження перед широким публічним запуском.
