Як ВАРТА працює
з вашими даними

Оновлено 21 жовтня 2026 року

ВАРТА — незалежний інформаційний проєкт з картою України та сповіщеннями про зміни стану тривоги. Для користування картою не потрібно створювати обліковий запис.

Налаштування на пристрої

На пристрої зберігаються обрана область, тема інтерфейсу та службовий токен керування push-підпискою. Вебзастосунок також кешує оболонку, шрифти й геометрію для запуску без мережі. Актуальні API-відповіді про тривоги не кешуються як підтверджений стан.

Сповіщення

Після надання дозволу для доставки повідомлень використовується OneSignal. Сервер ВАРТИ зберігає ідентифікатор push-підписки, обрану область, захищене представлення токена власника та службовий стан для уникнення повторної доставки. Назва області також передається OneSignal як налаштування підписки.

SDK OneSignal може обробляти ідентифікатори пристрою та підписки, push-токени, відомості про операційну систему, версію застосунку, сеанси використання й мережеві дані. Деталі: дані, які обробляє SDK, та політика OneSignal.

Геолокація

Місце визначається за вашим запитом кнопкою «Моє місце», щоб наблизити карту. ВАРТА не надсилає ці координати у власний API підписок. У нативних збірках location-модуль OneSignal вимкнений; геолокація карти працює окремо.

Мережеві сервіси

Сайт і API розміщені на Netlify, повідомлення доставляє OneSignal через браузерні push-служби, APNs або Firebase FCM. Моніторинг на карті використовує відкриті дані NEPTUN. При з’єднанні ці сервіси отримують технічні мережеві відомості, необхідні для роботи їхніх систем.

Ваш контроль

  • Вимкніть підписку в налаштуваннях ВАРТИ. Сервер прибере зв’язок підписки з областю й припинить відправлення.
  • Відкличте дозвіл на повідомлення або геолокацію в налаштуваннях браузера чи телефона.
  • Очистьте дані сайту або видаліть застосунок, щоб прибрати локальні налаштування. Для припинення серверної підписки скористайтеся відпискою до очищення даних.

Зв’язок

Питання щодо роботи проєкту можна залишити в репозиторії ВАРТИ. Це публічний канал: не додавайте приватні дані чи токени пристрою. Приватний контакт розробника буде додано перед публікацією магазинних версій.
